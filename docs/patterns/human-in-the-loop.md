:::note[Outline]

*Covered in **Module 09**.*

## What this page will cover

- Approval gates: before irreversible actions, above a cost threshold, below a confidence threshold
- What to show a reviewer: the plan, the diff, the tool call -- not the transcript
- Review fatigue as a failure mode: a gate that fires on everything gets approved on everything
- Escalation vs rejection vs correction, and how each feeds back into the run
- Using human decisions as eval data -- the cheapest labelled set you will ever get
