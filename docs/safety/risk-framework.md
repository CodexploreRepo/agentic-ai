# A risk framework

:::note[Outline]
This page is an outline with its sources identified. The prose lands with Module 09. The headings below are what it will contain -- useful already if you are deciding what to study next.
:::

*Covered in **Module 09**.*

## What this page will cover

- Scoring a task on reversibility, blast radius, and detectability -- not on how hard it is
- Mapping that score onto an autonomy level (see the autonomy spectrum)
- Threat modelling an agent: the tools are the attack surface
- Pre-launch checklist: guardrails placed, budgets set, traces on, approvals wired, rollback tested
- Incident response when an agent has already acted
- Where regulation is heading, kept deliberately brief and dated
