# No framework

:::note[Outline]
This page is an outline with its sources identified. The prose lands with a later module. The headings below are what it will contain -- useful already if you are deciding what to study next.
:::



## What this page will cover

- What you actually need: an HTTP client, a loop, a tool registry, and a trace. This repo's `src/` is about 1,200 lines of it
- What you give up: prebuilt integrations, a visual debugger, and someone else's opinion about state
- What you gain: every behaviour is inspectable, and upgrades are yours to schedule
- The honest threshold -- when a framework starts to pay for itself
