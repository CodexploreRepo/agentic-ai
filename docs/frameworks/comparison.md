## What this page will cover

- One task -- the Module 01 research brief -- built with no framework, Claude Agent SDK, OpenAI Agents SDK, and LangGraph
- Compared on: lines of code, pass rate on the shared eval set, cost per task, p50 latency, and debuggability
- What transferred unchanged (the prompts, the eval set) and what did not
- A decision table: pick by what you need, not by what is popular
- Standing caveat: these APIs move quarterly. Every number here is dated
