# Retrieval for agents

:::note[Outline]
This page is an outline with its sources identified. The prose lands with Module 06. The headings below are what it will contain -- useful already if you are deciding what to study next.
:::

*Covered in **Module 06**.*

## What this page will cover

- Difference from classic RAG: the agent chooses whether, when and what to retrieve -- retrieval becomes a tool
- Query rewriting and multi-query retrieval as agent steps
- Grounding and citation: making the agent say where each claim came from, and checking that it did
- Chunking and index design, briefly -- enough to be dangerous, with pointers to depth
- Evaluating retrieval separately from generation (component evals)
- Retrieved content is untrusted input (see Safety)
