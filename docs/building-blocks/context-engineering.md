# Context engineering

:::note[Outline]
This page is an outline with its sources identified. The prose lands with Module 06. The headings below are what it will contain -- useful already if you are deciding what to study next.
:::

*Covered in **Module 06**.*

## What this page will cover

- The reframing: not 'how do I prompt this' but 'what should be in the window at this step'
- Budgeting the window: instructions, tools, retrieved content, history -- each competing for the same space
- Tool output as the main uncontrolled consumer, and truncation as the first defence
- Position effects: material in the middle of a long context gets less attention than material at either end
- Prompt caching as an architectural concern -- stable prefixes are cheap, shuffled ones are not
- Just-in-time retrieval over up-front stuffing
