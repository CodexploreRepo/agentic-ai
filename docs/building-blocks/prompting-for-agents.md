# Prompting for agents

:::note[Outline]
This page is an outline with its sources identified. The prose lands with Module 03. The headings below are what it will contain -- useful already if you are deciding what to study next.
:::

*Covered in **Module 03**.*

## What this page will cover

- A system prompt for an agent answers: who you are, what you may do, when to stop, what to do when stuck
- Stop conditions in prose -- the most commonly missing piece, and the cause of most runaway loops
- Tool descriptions as part of the prompt surface
- Specifying output format and what to do when the format cannot be satisfied
- Anti-patterns: politeness instructions, 'think step by step' on reasoning models, and prompts that describe the happy path only
- Testing a prompt change the only way that counts -- against the eval set
