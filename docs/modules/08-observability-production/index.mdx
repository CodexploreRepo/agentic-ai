See what your agent did, what it cost, and why last Tuesday was worse.

## What you will be able to do

- Instrument an agent with OpenTelemetry and GenAI semantic conventions
- Choose what to log, and what never to log, when prompts contain user data
- Build the dashboard that matters: tool error rate, step distribution, step-limit hits, cost per successful task
- Turn production traces into tomorrow's eval cases
- Deploy with shadow runs and a canary gated on the eval set

## Build

**Lab 08 — From JSONL to a real collector**

Replace this repo's hundred-line tracer with OpenTelemetry, ship spans to a collector, and build the five charts that would have caught each of Module 04's deliberate failures before a user did.

## Takeaways this module is built around

1. Standard APM misses agent failures because nothing crashes
2. Cost per successful task is the metric; per-token cost hides retries
3. The loop closes when production traces become eval cases
