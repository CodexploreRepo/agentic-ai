# Modules

Nine modules, in order. Each one is a video, a set of pages, and a notebook you
can run.

Modules 01–05 follow the concept order of
[DeepLearning.AI's *Agentic AI* course](https://www.deeplearning.ai/courses/agentic-ai),
so the two interleave if you are taking it. Modules 06–09 cover the production
ground courses usually stop short of.

## How a module is put together

Every module has the same four parts, so you can pick the one you want:

- **Watch** — the video, for the shape of the idea
- **Read** — reference pages, for the detail
- **Build** — a notebook that uses the pattern, measures it, then breaks it
- **Evals** — the case set that makes the module's claim checkable

The written material is complete without the video, and the video is useful
without the reading. The lab is where it stops being theory.

## The thread running through all nine

Every module makes a claim — reflection improves drafts, planning helps on
multi-step tasks, a second agent earns its latency. Each one is tested against
an eval set rather than asserted, and sometimes the claim loses. Those are the
most useful modules.

See [eval-driven development](/evaluation/eval-driven-development) for why that
is the organising principle, and
[when not to use agents](/foundations/when-not-to-use-agents) for the
counterweight to the whole curriculum.
