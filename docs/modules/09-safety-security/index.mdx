## Build

**Lab 09 — Attack your own agent**

Run an indirect prompt injection against the Module 01 research agent via a page it fetches. Succeed. Then redesign so the same attack still succeeds at the model layer and no longer matters at the system layer — which is the only durable mitigation.

## Takeaways this module is built around

1. A guardrail the model can talk its way past is not a guardrail
2. Content marking is a mitigation, not a fix
3. Design so a successful injection is survivable, because some will succeed
