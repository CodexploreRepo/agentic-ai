Give an agent hands, and keep them where you can see them.

## What you will be able to do

- Write tool descriptions that actually drive correct selection
- Derive schemas from type hints so the two halves cannot drift
- Handle tool errors as a recovery channel rather than a crash
- Run model-written code without handing over your machine
- Measure tool-selection accuracy as its own component metric

## Build

**Lab 03 — An agent with a dangerous tool**

Add a Python execution tool to the Module 01 agent, then progressively contain it: subprocess, resource limits, filesystem policy, network policy. Each step is measured against an eval set that includes a case designed to escape.

## Takeaways this module is built around

1. A tool description is prompt, not documentation
2. Few broad tools beat many narrow ones for selection accuracy, up to a point you can measure
3. Code execution is the most useful tool and the one that demands the most containment
